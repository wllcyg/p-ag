# Presentation Design Skill · 演示文稿设计专家规范

本规范旨在消除 AI 生成演示文稿时千篇一律、枯燥死板的"灰色卡片堆砌"，通过**视觉隐喻（Visual Metaphors）**与**动态版式（Dynamic Layouts）**的深度绑定，生成极具视觉呼吸感、层次分明的高质感演示课件。

---

## 一、 核心设计哲学

1. **一页一主旨（One Idea Per Slide）**：每张幻灯片只聚焦一个核心教学/演说意图，严禁信息过载。
2. **拒绝死板方块（No Repetitive Boxes）**：根据页面内容的逻辑关系，必须使用最恰当的视觉版式。
3. **图文韵律感（Visual Rhythm）**：整套 PPT 必须具备快慢交替的视觉节奏（如：大字焦点页 → 流程时间轴页 → 双栏强对比页 → 四象限矩阵页）。

---

## 二、 5 大高级视觉版式与语义映射规则

| 版式类型 (`layout`) | 视觉隐喻 (Visual Metaphor) | 适用教学与演说场景 | 排版几何结构 |
|---|---|---|---|
| **`timeline`** (时间轴流式) | 递进主轴线 + 步骤发光圆球 (01~04) + 挂载卡片 | **教学过程全景脉络、实验推导步骤、历史演进线** | 顶部横向轴线贯穿，下方悬挂 3~4 个步骤内容卡片 |
| **`compare`** (双栏强对比) | 左侧重点蓝/紫 + 右侧难点红/橙 + 中间悬浮 VS 徽章 | **重点 vs 难点、宏观现象 vs 微观本质、传统模式 vs 创新探究** | 左右对称双分栏，各自包含 2~3 个层级要点，中央强对冲 |
| **`stat`** (观点大字焦点) | 左侧 38% 深色高亮金句 + 右侧 62% 解析卡片 | **三维教学目标确立、核心素养定位、教育理念提炼** | 左侧超大号醒目观点（大留白与呼吸感），右侧结构化拆解 |
| **`matrix`** (四象限矩阵) | 2x2 四大色块标头 + 象限分类卡片 (A/B/C/D) | **教材四大知识网络、多维学情画像（认知/能力/心理/难点）** | 2行2列整齐布局，适合并列的多维度解析 |
| **`grid`** (现代自适应网格) | 左侧主色细条 + 轻质圆角卡片 + 序号小标 | **常规知识点梳理、多项教学反思、课后拓展任务** | 2~3 列对称排布，字号自适应缩放 |

## 三、 页面类型 (`type`) 默认版式推荐表

```
1. cover    (封面页)       → 专属宽屏大标题母版 + 胶囊标签 + 元数据分割线
2. catalog  (说课提纲页)   → 双列大序号阶梯卡片 (01~06)
3. material (教材分析页)   → matrix (知识脉络四象限) 或 stat (核心地位大字)
4. student  (学情分析页)   → matrix (多维学情洞察) 或 stat (认知起点聚焦)
5. method   (教法重难点页) → compare (重点与难点左右双栏强对比)
6. process  (教学过程脉络) → timeline (四阶探究时间轴流式)
7. process  (核心探究展开) → grid (核心实验/互动活动展开)
8. board    (板书设计页)   → 核心主旨横幅 + 结构化网格卡片 (板块 01~06)
9. summary  (总结反思页)   → stat (预期成效与育人价值大字)
```

## 四、 字符密度与排版安全红线（Quality Gate）

1. **标题规范**：
   - 主标题：≤ 24 个汉字，简洁有力，拒绝拖沓长句；
   - 副标题：≤ 30 个汉字，注明学科、年级、教材版本或核心意图。
2. **要点文字**：
   - 单条 points 字符：**严格限制在 18 个汉字以内**（确保 16pt+ 字号下不换行折叠过密）；
   - 单页 points 数量：除封面外，每页保持 **2 ～ 6 条**，多于 6 条必须在渲染前拆为续页。
3. **演讲者逐字稿 (Speaker Notes)**：
   - 字数范围：每页 **80 ～ 180 字**（约 30~50 秒口播时长）；
   - 语调风格：口语化、富有启发性、符合特级教师现场说课的亲和力与权威感。

## 五、 配色系统规范（4 套专业主题）

* **灵动猫猫紫 (`cat-purple`)**：`#7C3AED` 主色 + `#A78BFA` 强调色 + `#F5F3FF` 极浅背景（适合文科、艺术、创意比赛）
* **极简科技蓝 (`tech-blue`)**：`#2563EB` 主色 + `#60A5FA` 强调色 + `#EFF6FF` 浅蓝背景（适合理工科、通用公开课、商业答辩）
* **清爽自然绿 (`fresh-mint`)**：`#059669` 主色 + `#34D399` 强调色 + `#ECFDF5` 薄荷背景（适合生物、地理、自然科学）
* **典雅学术红 (`academic-red`)**：`#DC2626` 主色 + `#F87171` 强调色 + `#FEF2F2` 典雅背景（适合思政、历史、正式答辩）
